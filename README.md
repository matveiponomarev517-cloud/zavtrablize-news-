# Завтра ближе — автоматическая редакция

Каждые 30 минут GitHub Actions запускает бота: RSS → Gemini → обложка → Telegram @zavtrablize. Оттуда посты забирает бот Дзена. За запуск выходит не больше одной публикации, за сутки — не больше 3. База SQLite (`news.db`) сохраняется коммитом между запусками. Вмешательство не требуется.

## Что публикуется
Форматы чередуются автоматически (8 постов по кругу): новость → «Простыми словами» → новость → **лонгрид** → **«Сегодня в истории науки»** → вопрос читателям → новость → «Простыми словами». «Сегодня в истории науки» берёт научные события этого дня из Википедии (раз в сутки; нет подходящего события — выходит обычная новость).

**Источники:** 17 лент (ScienceDaily, NASA, ESA, ESO, MIT News, IEEE Spectrum, Science News, Quanta, New Scientist, Phys.org, Ars Technica, Universe Today и др.) по темам: наука, космос, технологии, здоровье, экология. Бот выбирает новость с сайта и темы, которых меньше всего среди последних 10 постов, поэтому канал не превращается в один источник. Нерабочая лента не ломает запуск, в логе будет предупреждение `RSS ...`, а строку можно удалить из списка `RSS` в `newsbot.py`. По воскресеньям после 18:00 МСК выходят **«Итоги недели»** — собираются из заголовков постов за неделю, ничего нового не добавляется.

- **Обложка** 1280×720 в каждом посте: фон рисует Gemini по описанию от редактора-модели, поверх — фирменный заголовок и метка формата. Если нейросеть недоступна (лимиты бесплатного тарифа, ошибка), обложка собирается из градиента, пост не пропадает. Если не получилась и она — пост уходит текстом.
- **Лонгрид** (статья 1800–3200 знаков) пишется по полному тексту страницы и только для источников NASA и ESA (открытые материалы). Если текст не получилось скачать, выходит обычная новость. Статья идёт ответом на пост-анонс.
- Темы не повторяются: бот видит последние публикации и отклоняет дубли; кроме того, одна ссылка и один заголовок не публикуются дважды.
- Фото-пост: подпись к фото в Telegram — до 1024 знаков. Если текст длиннее, он идёт сообщением следом за фото.

## Подготовка
1. Загрузите все файлы, включая скрытую папку `.github/workflows/` и папку `fonts/` (шрифт для обложек). Репозиторий лучше сделать **приватным**.
2. Settings → Secrets and variables → Actions → добавьте секреты:
   - `GEMINI_API_KEY` — ключ из Google AI Studio.
   - `TELEGRAM_BOT_TOKEN` — токен бота; бот — администратор канала с правом публикации.
   - `TELEGRAM_CHANNEL` — `@zavtrablize` (необязательно, это значение по умолчанию).
   - `TELEGRAM_ADMIN_ID` — числовой ID для уведомлений (необязательно, но рекомендуется).
3. Settings → Actions → General → Workflow permissions → **Read and write permissions**.
4. Actions → Zavtra Blizhe News → Run workflow. Ручной запуск игнорирует окно времени и паузу, но не дневной лимит.

## Настройки (переменные окружения в воркфлоу)
| Переменная | По умолчанию | Смысл |
|---|---|---|
| `POST_SLOTS` | 9,14,19 | часы (МСК), с которых положен очередной пост |
| `MAX_PER_DAY` | 3 | публикаций в сутки (по МСК) |
| `MIN_GAP_MINUTES` | 90 | пауза между публикациями |
| `POST_HOUR_FROM` / `POST_HOUR_TO` | 8 / 23 | окно публикаций, МСК |
| `COVERS` | 1 | `0` — вообще без обложек |
| `AI_COVERS` | 1 | `0` — только градиентные обложки, без нейросети |
| `LONGREADS` | 1 | `0` — отключить лонгриды |
| `WEB_SCOUT` | 1 | `0` — не искать новости по всему интернету, только RSS |
| `MAX_AI_IMAGES_PER_MONTH` | 100 | потолок платных ИИ-картинок в месяц |
| `DIGEST_WEEKDAY` / `DIGEST_HOUR` | 6 / 18 | день (0=пн) и час итогов недели, МСК |
| `SILENCE_ALERT_HOURS` | 36 | через сколько часов без постов предупредить админа |
| `GEMINI_MODEL` | авто | принудительно выбрать текстовую модель |

## Поиск по всему интернету
Через раз бот берёт новость не из RSS, а находит её сам: Gemini с поиском Google ищет свежие материалы по теме (темы идут по кругу: космос, ИИ, медицина, физика, климат, биология, инженерия, нейронаука, математика). Каждую найденную ссылку бот открывает сам, проверяет дату и текст, а пост пишется по реальному тексту страницы, а не по пересказу модели. Ссылки на соцсети, видео и IP-адреса отбрасываются.

## Стиль
Промпт задаёт голос живого автора: разговорный язык, оценки и ирония, без штампов («учёные выяснили», «стоит отметить»), но без выдуманного личного опыта и цитат. Зачин каждый раз другой, и бот знает начала последних 5 постов, чтобы не повторяться.

## Месячный отчёт
1–5 числа в личку (`TELEGRAM_ADMIN_ID`, нужно сначала написать боту /start) приходит итог месяца: сколько постов, форматы, темы, источники, обложки и их примерная стоимость, поиски Gemini, ленты, которые часто не загружались.

## Лимиты и стоимость
- **Частота:** 3 публикации в сутки по слотам: утром (с 9:00), днём (с 14:00) и вечером (с 19:00 МСК). Слоты настраиваются в `POST_SLOTS`. GitHub иногда пропускает или задерживает запуски по расписанию, поэтому бот просыпается каждые 30 минут с 8:17 до 22:47. Если слот пропущен, ближайший запуск «догонит» недостающий пост (пауза между постами — 90 минут). Запуски, которым публиковать нечего, заканчиваются за секунды, не обращаясь к Gemini.
- **Обращения к Gemini:** в среднем 5–15 в сутки (текст — бесплатно на бесплатном ключе, у ключа есть свои дневные лимиты, но этого объёма они не достигают).
- **GitHub Actions:** ≈900 коротких запусков в месяц (около минуты каждый); для публичного репозитория бесплатно, для приватного это ≈ 1000–1300 минут из 2000 бесплатных.
- **Подписка Google AI Pro/Ultra не увеличивает лимиты API:** по правилам Google она действует в AI Studio в браузере, а ключ API оплачивается отдельно (Cloud Billing).
- **ИИ-картинки на бесплатном ключе недоступны**, поэтому обложки будут градиентными. Если подключить оплату в AI Studio, картинка стоит ≈ $0.04, то есть до ≈ $3–4 в месяц при 3 постах в день, потолок задаётся `MAX_AI_IMAGES_PER_MONTH`. После отказа API бот 12 часов не пробует ИИ-картинки снова.
- **Поиск Google в Gemini:** на бесплатном уровне есть квота (для моделей 2.5 — 500 запросов в сутки, для моделей 3 — 5000 в месяц), бот использует 1 запрос за публикацию. За пределами квоты поиск платный, а при ошибке бот просто работает по RSS.

## Проверьте на стороне Дзена
Как именно бот Дзена переносит посты, зависит от его настроек, и в этом репозитории это не проверяется. После первых публикаций посмотрите в Дзене, что:
- пост с фото и подписью импортируется целиком;
- лонгрид (пост + ответ со статьёй) не ломается. Если ломается — поставьте `LONGREADS=0`.

## Если не работает
Причина пишется в лог запуска (Actions), в статус записи в `news.db` и, если задан `TELEGRAM_ADMIN_ID`, в Telegram. Если давно нет публикаций — придёт отдельное предупреждение.
- `HTTP 404 от api.telegram.org` — неверный токен бота.
- `HTTP 400 ... chat not found` — неверный `TELEGRAM_CHANNEL` или бот не добавлен в канал.
- `HTTP 404/403 от generativelanguage.googleapis.com` — неверный ключ или недоступна модель (`GEMINI_MODEL`).
- В логе «ИИ-картинка недоступна, рисую градиент» — штатно: обложка есть, но без нейросети.
- Новость, которая трижды закончилась ошибкой, больше не пробуется.

## Заметки
- Фильтр ИИ и срок новостей (14 дней) не заменяют проверку источников — ошибки возможны. Статьи пересказываются своими словами со ссылкой на источник; картинки из источников не используются.
- Шрифт DejaVu Sans Bold в `fonts/` распространяется по свободной лицензии.
- Не публикуйте секреты в чате и коде.
