# Завтра ближе — автоматическая редакция

GitHub Actions раз в час запускает бота: RSS → Gemini → Telegram @zavtrablize. За запуск публикуется не больше одного поста, за день — не больше 3. База SQLite (`news.db`) сохраняется коммитом между запусками.

## Подготовка
1. Загрузите все файлы в репозиторий, включая скрытую папку `.github/workflows/`. Лучше сделать репозиторий **приватным**: в нём лежит история постов.
2. Settings → Secrets and variables → Actions → добавьте секреты:
   - `GEMINI_API_KEY` — ключ из Google AI Studio.
   - `TELEGRAM_BOT_TOKEN` — токен бота (от @BotFather). Бот должен быть администратором канала с правом публикации.
   - `TELEGRAM_CHANNEL` — `@zavtrablize` (необязательно, это значение по умолчанию).
   - `TELEGRAM_ADMIN_ID` — числовой ID для уведомлений об ошибках (необязательно).
3. Settings → Actions → General → Workflow permissions → **Read and write permissions**.
4. Actions → Zavtra Blizhe News → Run workflow. Ручной запуск игнорирует окно времени и паузу, но не дневной лимит.

## Поведение (настраивается переменными окружения)
| Переменная | По умолчанию | Смысл |
|---|---|---|
| `MAX_PER_DAY` | 3 | постов в сутки (сутки по МСК) |
| `MIN_GAP_MINUTES` | 120 | минимальная пауза между постами |
| `POST_HOUR_FROM` / `POST_HOUR_TO` | 8 / 23 | окно публикаций, МСК |
| `GEMINI_MODEL` | авто | принудительно выбрать модель |

Модель выбирается автоматически: стабильные `flash-lite`, затем `flash`; модели для картинок, речи и экспериментальные исключаются.

## Если не работает
Причина ошибки пишется в лог запуска (Actions) и в статус записи в `news.db`; если задан `TELEGRAM_ADMIN_ID`, она приходит и в Telegram.
- `HTTP 404 от api.telegram.org` — неверный токен бота.
- `HTTP 400 ... chat not found` — неверный `TELEGRAM_CHANNEL` или бот не добавлен в канал.
- `HTTP 404/403 от generativelanguage.googleapis.com` — неверный ключ или недоступна модель; задайте `GEMINI_MODEL`.
- Новость, которая трижды закончилась ошибкой, больше не пробуется.

## Заметки
- Фильтр ИИ и срок новостей (14 дней) не заменяют проверку источников — ошибки возможны.
- Архив в Google Docs/Sheets не реализован намеренно, чтобы не усложнять запуск.
- Не публикуйте секреты в чате и коде.
