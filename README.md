# Завтра ближе — автоматическая редакция

Раз в час GitHub Actions запускает бота: RSS → Gemini → обложка → Telegram @zavtrablize. Оттуда посты забирает бот Дзена. За запуск выходит не больше одной публикации, за сутки — не больше 3. База SQLite (`news.db`) сохраняется коммитом между запусками. Вмешательство не требуется.

## Что публикуется
Форматы чередуются автоматически (6 постов по кругу): новость → «Простыми словами» → новость → **лонгрид** → вопрос читателям → новость. По воскресеньям после 18:00 МСК выходят **«Итоги недели»** — собираются из заголовков постов за неделю, ничего нового не добавляется.

- **Обложка** 1280×720 в каждом посте: фон рисует Gemini по описанию от редактора-модели, поверх — фирменный заголовок и метка формата. Если нейросеть недоступна (лимиты бесплатного тарифа, ошибка), обложка собирается из градиента, пост не пропадает. Если не получилась и она — пост уходит текстом.
- **Лонгрид** (статья 1800–3200 знаков) пишется по полному тексту страницы и только для источников NASA и ESA (открытые материалы). Если текст не получилось скачать, выходит обычная новость. Статья идёт ответом на пост-анонс.
- Темы не повторяются: бот видит последние публикации и отклоняет дубли; кроме того, одна ссылка и один заголовок не публикуются дважды.
- Фото-пост: подпись к фото в Telegram — до 1024 знаков. Если текст длиннее, он идёт сообщением следом за фото.

## Подготовка
1. Загрузите все файлы, включая скрытую папку `.github/workflows/` и папку `fonts/` (шрифт для обложек). Репозиторий лучше сделать **приватным**.
2. Settings → Secrets and variables → Actions → добавьте секреты:
   - `GEMINI_API_KEY` — ключ из Google AI Studio.
   - `TELEGRAM_BOT_TOKEN` — токен бота; бот — администратор канала с правом публикации.
   - `TELEGRAM_CHANNEL` — `@zavtrablize` (необязательно, это значение по умолчанию).
   - `TELEGRAM_ADMIN_ID` — числовой ID для уведомлений (необязательно, но рекомендуется).
3. Settings → Actions → General → Workflow permissions → **Read and write permissions**.
4. Actions → Zavtra Blizhe News → Run workflow. Ручной запуск игнорирует окно времени и паузу, но не дневной лимит.

## Настройки (переменные окружения в воркфлоу)
| Переменная | По умолчанию | Смысл |
|---|---|---|
| `MAX_PER_DAY` | 3 | публикаций в сутки (по МСК) |
| `MIN_GAP_MINUTES` | 120 | пауза между публикациями |
| `POST_HOUR_FROM` / `POST_HOUR_TO` | 8 / 23 | окно публикаций, МСК |
| `COVERS` | 1 | `0` — вообще без обложек |
| `AI_COVERS` | 1 | `0` — только градиентные обложки, без нейросети |
| `LONGREADS` | 1 | `0` — отключить лонгриды |
| `DIGEST_WEEKDAY` / `DIGEST_HOUR` | 6 / 18 | день (0=пн) и час итогов недели, МСК |
| `SILENCE_ALERT_HOURS` | 36 | через сколько часов без постов предупредить админа |
| `GEMINI_MODEL` | авто | принудительно выбрать текстовую модель |

## Проверьте на стороне Дзена
Как именно бот Дзена переносит посты, зависит от его настроек, и в этом репозитории это не проверяется. После первых публикаций посмотрите в Дзене, что:
- пост с фото и подписью импортируется целиком;
- лонгрид (пост + ответ со статьёй) не ломается. Если ломается — поставьте `LONGREADS=0`.

## Если не работает
Причина пишется в лог запуска (Actions), в статус записи в `news.db` и, если задан `TELEGRAM_ADMIN_ID`, в Telegram. Если давно нет публикаций — придёт отдельное предупреждение.
- `HTTP 404 от api.telegram.org` — неверный токен бота.
- `HTTP 400 ... chat not found` — неверный `TELEGRAM_CHANNEL` или бот не добавлен в канал.
- `HTTP 404/403 от generativelanguage.googleapis.com` — неверный ключ или недоступна модель (`GEMINI_MODEL`).
- В логе «ИИ-картинка недоступна, рисую градиент» — штатно: обложка есть, но без нейросети.
- Новость, которая трижды закончилась ошибкой, больше не пробуется.

## Заметки
- Фильтр ИИ и срок новостей (14 дней) не заменяют проверку источников — ошибки возможны. Статьи пересказываются своими словами со ссылкой на источник; картинки из источников не используются.
- Шрифт DejaVu Sans Bold в `fonts/` распространяется по свободной лицензии.
- Не публикуйте секреты в чате и коде.
